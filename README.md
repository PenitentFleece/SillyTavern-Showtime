# Showtime

A [SillyTavern](https://github.com/SillyTavern/SillyTavern) production desk: Cast, Script, Library, Inventory, Reputation, Motivation, Composer, and Backstage (Director, Interview, Set, trackers, effects).

## Install

Use SillyTavern’s built-in extension installer — paste the GitHub URL, nothing to unzip.

1. Open **Extensions** → **Install Extension**
2. Paste:
   ```
   https://github.com/penitentfleece/SillyTavern-Showtime
   ```
3. Click **Install** and reload if prompted

Updates after that: **Extensions** → Showtime → **Update**.

## After install

The cream **Showtime** bar sits above chat. With no chat selected the curtain stays down; open a chat and it draws back.

- **Cast** — Star, Director, billing, stats, wardrobe, pronouns
- **Script** — scene cards, timeline, Agent
- **Library** — lore cubbies and tags
- **Inventory** — trunk vs on-person
- **Reputation** — Connections web and affiliations
- **Motivation** — secrets, beats, who knows what
- **Composer** — scene music (Spotify PKCE; client ID only, no secret)
- **Backstage** — Director events, Interview, Peanut Gallery, Set / Compass, trackers, weather overlay

Hard-reload (Ctrl+F5) after a first install if the marquee does not appear — SillyTavern caches extension JS.

## Requirements

SillyTavern recent `release` / `staging`. No extra Node packages.
